# Basic Arithmetic Calculator

## Purpose
A simple C++ calculator that performs addition, subtraction,
multiplication and division on two numbers.

## How to Run
g++ lab06_git.cpp -o lab06_git
.\lab06_git.exe

## Example Input/Output
Enter first number: 10
Enter operator (+, -, *, /): /
Enter second number: 2
Result: 5
